Settings & Notes

This is a single-file, offline-capable ISC caseload tool. Data never leaves your device unless you export it.

  • Browser notifications work when the page is open and permission is granted.
  • For real SMS / phone alerts, connect a service such as Twilio or a no-code tool (Make.com / Zapier) that watches an exported webhook or email.
  • AI helpers (summarize, draft updates) run entirely in the browser. For stronger LLM assistance, you can later add an API key to a secure backend.
  • Large file attachments are stored as base64 — keep them modest or clear periodically.
